# DailyMart BD 🛒
> **Fresh Products. Fair Prices. Delivered Daily.**

A modern, production-ready, full-featured multi-category Bangladeshi online grocery & daily essentials e-commerce website.

---

## 🌟 Key Features

### 1. 🛍️ Comprehensive Product Catalog & Categories
- **14 Major Categories**:
  - Vegetables (আলু, পেঁয়াজ, টমেটো, রসুন, আদা, গাজর, ফুলকপি, বেগুন, শসা, মরিচ, ইত্যাদি)
  - Fruits (আম, কলা, আপেল, কমলা, পেঁপে, তরমুজ, আঙুর, ইত্যাদি)
  - Fish & Seafood (ইলিশ, রুই, কাতলা, বাগদা চিংড়ি, পাবদা, তেলাপিয়া)
  - Meat (ব্রয়লার ও দেশি মুরগি, গরুর মাংস, খাসির মাংস, হাঁস)
  - Eggs & Dairy (ডিম, তরল দুধ, মিষ্টি ও টক দই, মাখন ও ঘি)
  - Rice & Grains (মিনিকেট চাল, নাজিরশাইল, বিরই, ডাল, আটা ও ময়দা)
  - Oil & Spices (রূপচাঁদা ও তীর সয়াবিন তেল, সরিষার তেল, মসলা)
  - Snacks & Biscuits, Beverages (চা, কফি, জুস), Frozen Food, Household, Personal Care, Baby Products, Kitchen Essentials.
- **50+ Carefully Curated Products** with high-resolution food photography.
- **Multi-variant system**: Select by weight (250g, 500g, 1kg, 2kg, 5kg), grade (Grade A+, Grade A, Grade B), pack size, cut pieces, etc. Dynamic price calculation updates instantly.

### 2. 🇧🇩 Bangladesh-Centric Experience
- **Currency**: Bangladeshi Taka (৳) formatting on all products, carts, and invoices.
- **Payment Methods**: Cash on Delivery (COD), bKash, Nagad, and Card payments.
- **District Delivery**: Full coverage selector supporting all 64 districts of Bangladesh.
- **Mobile Number Validation**: Bangladeshi standard 01XXXXXXXXX phone number validation.
- **Local Language Terminology**: Ilish, Rui, Khashi, Begun, Kacha Morich, Deshi Murgi, etc.

### 3. ⚡ Dynamic Shopping Experience (SPA Architecture)
- **Hash-based Client-side Router** covering all standard e-commerce flows (Home, Categories, Product Detail, Cart, Checkout, Order Confirmation, Search, Wishlist, Account).
- **Slide-out Cart Drawer** & Instant Search with Autocomplete.
- **Persistent State** via LocalStorage.

## 🚀 How to Run the Website

### Option 1: Direct Browser Open (Simplest)
Open index.html directly in any web browser:
e:\web site\index.html

### Option 2: Run with Python HTTP Server
`powershell
python -m http.server 8000
`
Then visit: http://localhost:8000
